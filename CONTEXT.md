# Portfolio Language

Canonical names for the company and products described on drepkovsky.com.

## Language

**QUESTPIE s.r.o.**:
The software company Dominik founded while studying at FIIT STU. It does contract product work and develops its own tools.
_Avoid_: QUESTPIE Studio, agency

**QUESTPIE Framework**:
The current server-first TypeScript backend framework built by QUESTPIE s.r.o. It is a framework, not a CMS.
_Avoid_: QUESTPIE CMS, CMS

**QUESTPIE Autopilot**:
The agent runtime for operating long-running company work with goals, tasks and an auditable filesystem record.
_Avoid_: AI assistant, chatbot

**Crust**:
The retired Payload-based framework that preceded QUESTPIE Framework. It is presented as an archived reference, not as a current dependency.
_Avoid_: QUESTPIE Studio, QUESTPIE CMS, current QUESTPIE

**Jubli**:
An active QUESTPIE product for event-based social spaces across web and mobile.
